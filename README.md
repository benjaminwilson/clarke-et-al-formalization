# Formal proof of the offline memory checking argument of Clarke et al. (2003)

The memory checker of [Incremental Multiset Hash Functions and Their Application to Memory Integrity Checking](https://people.csail.mit.edu/devadas/pubs/mhashes.pdf) (Clarke et al., 2003) is sound, but the soundness proof they give in Appendix E has problems. We presented an alternative proof in [this blog post](https://building-babylon.net/2026/11/04/a-soundness-proof-for-the-offline-memory-checker-of-clarke-et-al-2003/). This repository contains a Lean formalization of the alternative proof.  The Lean code generated by GPT 6 Astra.  I have checked, however, that the theorem statements correspond to the statements in the blog post.
